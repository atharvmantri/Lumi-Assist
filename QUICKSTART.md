# Lumi Quick Start Guide

## First-Time Setup

From PowerShell in the repository folder:

```powershell
.\install.bat
```

The installer:

1. Requires/installs Python 3.11
2. Creates an isolated `venv`
3. Installs Lumi's packages into that exact venv
4. Uses CPU-safe speech-to-text by default, or enables CUDA when an NVIDIA GPU is available
5. Downloads the Piper voice files into the path Lumi actually reads
6. Saves your API/provider choices in `.env` + `config.local.yaml`
7. Runs a dependency preflight and diagnostics

## Reviewer / Debug Launch

Use the terminal launcher when testing or certifying the project:

```powershell
.\launch_voice.bat
```

It prints the exact Python interpreter and NumPy version in use, repairs missing venv packages automatically, and keeps the terminal open if startup fails.

> **Important:** do not troubleshoot Lumi with a bare `pip install numpy`. On Windows that may install into a different Python (for example Python 3.12) while Lumi runs `venv\Scripts\python.exe` (Python 3.11). Use:
>
> ```powershell
> .\venv\Scripts\python.exe -m pip install -r requirements.txt
> ```

For normal tray mode:

```powershell
.\launch.bat
```

## Once Lumi Is Running

1. Say **"hey lumi"**
2. Wait for the chime
3. Speak your request
4. Lumi transcribes, calls the configured LLM/tools, and replies out loud

The first wake-word/STT use may download a Whisper model if it is not cached yet.

## Health Checks

```powershell
.\venv\Scripts\python.exe -m core.diagnostics
.\venv\Scripts\python.exe tests\test_quick.py
```

`core.diagnostics` checks the actual venv, config, API key, Piper files, audio devices, screen capture, and Qt overlay. A failed check returns a non-zero exit code.

## What Lumi Can Do

- Open and focus apps
- Control media/volume
- Inspect CPU, RAM, battery, processes, disks and network state
- Search the web and fetch pages
- Work with files, notes, tasks, timers and conversation history
- Take screenshots / use screen tools
- Execute registered automation and developer tools

Browse `docs/TOOLS.md` for the full tool catalog.

## Command-Line Modes

Always use Lumi's venv interpreter:

```powershell
.\venv\Scripts\python.exe main.py             # Full voice loop + tray
.\venv\Scripts\python.exe main.py --type      # Text mode
.\venv\Scripts\python.exe main.py --dry-run   # Synthetic test turn
.\venv\Scripts\python.exe main.py --no-tray   # Terminal-only voice loop
```

## Configuration

- `config.yaml` — repository defaults; CPU-safe on a fresh clone
- `config.local.yaml` — machine/provider overrides generated by the installer
- `.env` — API key for the provider selected during install

Example:

```yaml
stt:
  model: "large-v3-turbo"
  device: "cuda"
  compute_type: "float16"
```

## Troubleshooting

- **`ModuleNotFoundError: No module named 'numpy'`** — run `.\repair_env.bat`; do not install NumPy into global Python.
- **Wake word does nothing** — run `.\launch_voice.bat` and watch the `[ww]` lines; the fresh-install fallback no longer requires a trained wake-word model.
- **TTS files missing** — re-run `.\install.bat` so the Piper model/config are downloaded to `models\piper\`.
- **No mic/speakers detected** — run `.\venv\Scripts\python.exe -m core.diagnostics` and inspect the audio-device check.
- **GPU/CUDA error** — set `stt.device: "cpu"` and `stt.compute_type: "int8"` in `config.local.yaml`, or re-run the installer.
